# Golem

## Memory
Your context resets; this repo doesn't. `WORKLOG.md` is your external memory, shared with every agent that works here. Read it when you start or resume. Keep whatever a later session would need but couldn't get from the code or git history; what that is, and how you shape it, is up to you. It's committed, so never write secrets into it.

Memory drifts as the work moves on, and a wrong note misleads every later session. Dream when you judge it's needed: check the memory against the repo, git log and test output, which are the ground truth, so it stays correct, current and short enough to read in full. Agents that rewrite the same page lose each other's work, so give parallel work its own file.
